# Git Carpeta666

Repositorio de ejemplo para practicar Git, ramas, merges y commits.

## Archivos del proyecto
- **archivo.py**: Script principal en la carpeta raíz.
- **iniciar_ssh.sh**: Script de shell para iniciar SSH o pruebas de conexión.
- **prueba2.txt**: Archivo de texto de prueba.
- **proyecto_git/main.py**: Archivo principal dentro de la subcarpeta `proyecto_git`.
- **proyecto_git/funcion_n.py**: Archivo de funciones dentro de la subcarpeta `proyecto_git`.

## Ramas
- **main**: Rama principal del proyecto. Contiene los archivos finales.
- **rama_primera**: Rama de práctica para crear nuevos archivos y cambios.
- **rama_segunda**: Rama de práctica adicional para experimentar.
- **rama_2**: Rama para pruebas de desarrollo y cambios secundarios.
- **rama_3**: Rama para practicar merges y resolver conflictos.

## Cómo usar
Este repositorio es solo para práctica de Git.
